🛠️ Reusable Experiment Harness (scripts/gauntlet_harness.py)

Built for repeatable execution, clean-room physical isolation, automated rule verification, and output certification.

To test any future game prompt or model through the Gauntlet, use the unified CLI harness: 

# 1. Lock down existing baseline repositories (chmod 000 clean-room isolation)
./scripts/gauntlet_harness.py isolate

# 2. Prepare environment and validate prompt file
./scripts/gauntlet_harness.py prepare gauntlet/<model>/<game>/PROMPT.md

# 3. Validate generated single-file game against benchmark rules (Canvas, AudioContext, 0 external assets)
./scripts/gauntlet_harness.py validate gauntlet/<model>/<game>/index.html

# 4. Save certified Golden Master and restore normal repo permissions
./scripts/gauntlet_harness.py save gauntlet/<model>/<game>/PROMPT.md --code-file output.html
./scripts/gauntlet_harness.py restore
