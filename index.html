The 5 Golden Rules of the Benchmark

Strict experimental controls designed to push AI models to the limits of autonomous synthesis.

RULE 01

Pure One-Shot Prompt

Zero human iteration or debugging. The model is given a single multi-page specification. Its very first output must run directly in a browser without edits.

RULE 02

Zero External Assets

No external spritesheets, images, audio samples, or fonts. 100% of graphics are drawn via canvas math and 100% of audio is synthesized via Web Audio nodes.

RULE 03

Zero Dependencies

Pure Vanilla JavaScript, HTML5 Canvas, and Web Audio API. Third-party game engines (Phaser, Three.js) or audio libraries (Tone.js, Howler) are strictly banned.

RULE 04

Demoscene Authenticity

Strict adherence to classic PC / Amiga hardware constraints: 320×200 software framebuffers, EGA/VGA palettes, and authentic OPL2 FM / Amiga MOD tracker engines.

RULE 05

Full Game Depth

Not trivial tech demos. Each game must feature multi-level progression, unique audio arrangements per world, full boss fights, power-up systems, and win/loss states.

How to Re-Run the Experiment with a New Model

Instructions for testing an AI model against the 4 Slopanoid challenges.

  1. Create the target model directory: e.g., mkdir gemini-3.8-flash, mkdir gemini-4-argon, or mkdir fable-5.1.
  2. Select a challenge prompt: Copy one of the 4 verbatim prompts:
    • opus-5.5/arkanoid/PROMPT.md
    • opus-5.5/xenon2/PROMPT.md
    • opus-5.5/ghosts-n-goblins/PROMPT.md
    • opus-5.5/lemmings/PROMPT.md
  3. Submit as a single prompt in a clean context: Do not add follow-up nudges or bug fix instructions.
  4. Save output directly: Write the generated single file or folder into <model-name>/<game>/index.html.
  5. Evaluate against the 5 Golden Rules: Verify that audio plays without external assets, controls respond cleanly, and canvas scales crisply.
