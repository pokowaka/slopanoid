# Slopanoid: Autonomous Game Dev Benchmark

An empirical benchmark testing the boundaries of frontier AI models at generating complete, complex, fully playable retro games via **single one-shot prompts** with zero human intervention.

Every game in this benchmark is built under strict constraints:
- **Zero External Assets**: No external sprite sheets, images, sound clips, or music files. Everything is procedurally rendered to canvas and dynamically synthesized via Web Audio API (FM synthesis, MOD tracker, wavetables).
- **Zero External Libraries**: Pure Vanilla JavaScript, HTML5 Canvas, and CSS. No game engines or audio frameworks.
- **Hardware & Demoscene Authenticity**: 320×200 software framebuffers, custom EGA/VGA palettes, AdLib/OPL2 FM synthesizers, and Amiga Paula-style MOD tracker engines.

## 🚀 Quick Start

Open the benchmark hub in any modern browser:

```bash
# Open the master benchmark hub
open index.html

# Or launch the Opus 5.5 showcase directly
open opus-5.5/index.html
```

Or serve locally with any static web server:

```bash
npx serve .
# or
python3 -m http.server 8000
```
